# 📦 Basic Express App

This is a simple Express.js application that serves as a starter project for building REST APIs using Node.js and Express. It includes a basic setup with a root route and JSON parsing middleware.

---

## 🚀 Features

- Basic Express server setup
- Parses incoming JSON using `express.json()`
- One sample route: `/` with a welcome message
- Easy to expand into a full API project

---

## 🛠️ Tech Stack

- Node.js
- Express.js
